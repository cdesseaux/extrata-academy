# 🔌 EXTRATA ACADEMY - API Specification

## 📋 Overview

**Base URL**: `http://localhost:4000/api` (development)  
**Production URL**: `https://api.academy.extrata.gov.br/api`  
**API Version**: v1  
**Authentication**: JWT Bearer Token (OAuth2/OIDC via Keycloak)  
**Content-Type**: `application/json`

---

## 🔐 Authentication

### POST /auth/login
**Description**: Redirect to Keycloak for authentication

**Request**:
```http
POST /api/auth/login
Content-Type: application/json
```

**Response**:
```json
{
  "redirect_url": "https://keycloak.example.com/auth/realms/extrata/protocol/openid-connect/auth?..."
}
```

### GET /auth/callback
**Description**: OAuth callback endpoint

**Query Parameters**:
- `code` (string, required): Authorization code from Keycloak

**Response**:
```json
{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 900,
  "user": {
    "id": "uuid",
    "email": "user@example.com",
    "name": "User Name",
    "role": "STUDENT"
  }
}
```

### POST /auth/refresh
**Description**: Refresh access token

**Request**:
```json
{
  "refresh_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**Response**: Same as `/auth/callback`

### POST /auth/logout
**Description**: Logout and invalidate tokens

**Headers**:
```
Authorization: Bearer {access_token}
```

**Response**:
```json
{
  "message": "Logged out successfully"
}
```

- `category` (string, optional): Filter by category
- `difficulty_level` (string, optional): iniciante | intermediario | avancado
- `search` (string, optional): Search in title/description

- `limit` (number, optional, default: 20, max: 100)

## ⚠️ Error Responses

### Standard Error Format

```json
{
  "statusCode": 400,
  "message": "Validation failed",
  "error": "Bad Request",
  "details": [
    {
      "field": "title",
      "message": "title should not be empty"
    }
  ]
}
```

### Common Status Codes

- `200` - Success
- `201` - Created
- `204` - No Content
- `400` - Bad Request (validation error)
- `401` - Unauthorized (missing/invalid token)
- `403` - Forbidden (insufficient permissions)
- `404` - Not Found
- `409` - Conflict (duplicate resource)
- `422` - Unprocessable Entity (business logic error)
- `429` - Too Many Requests (rate limit)
- `500` - Internal Server Error

---

## 🔒 Rate Limiting

- **Authenticated requests**: 1000 requests per 15 minutes
- **Unauthenticated requests**: 100 requests per 15 minutes
- **Headers**:
  ```
  X-RateLimit-Limit: 1000
  X-RateLimit-Remaining: 995
  X-RateLimit-Reset: 1704556800
  ```

**Query Parameters**:

  "meta": {
