# 👨‍🎓 MANUAL DO ALUNO

## 🚀 Primeiros Passos

### 1. Fazendo Login

**Acesso via Extrata:**
1. Faça login no sistema Extrata (https://extrata.gov.br)
2. Clique em **"Academy"** no menu superior
3. Você será automaticamente autenticado no Academy

**Acesso direto:**
1. Acesse https://academy.extrata.gov.br
2. Clique em **"Entrar com Extrata"**
3. Use suas credenciais do Extrata
4. Aceite os termos de uso e política de privacidade

### 2. Configurando seu Perfil

Após o primeiro login:

1. Clique na sua **foto de perfil** (canto superior direito)
2. Selecione **"Meu Perfil"**
3. Complete as informações:
   - ✅ Nome completo
   - ✅ Email de contato
   - ✅ Telefone (opcional)
   - ✅ Foto de perfil (opcional)
   - ✅ Preferências de notificação

**Dica:** 💡 Uma foto de perfil ajuda a criar conexão com outros usuários!

## 🎓 Fazendo um Curso

### 1. Encontrando Cursos

**No catálogo:**
1. Clique em **"Cursos"** no menu
2. Use os filtros:
   - 📁 Categoria (Fundamentos, Avançado, etc.)
   - 📊 Nível (Iniciante, Intermediário, Avançado)
   - 🔍 Busca por palavra-chave

**Cursos recomendados:**
- O sistema sugere cursos baseados no seu perfil
- Cursos pré-requisitos aparecem destacados

### 2. Matriculando-se em um Curso

1. Clique no **card do curso** desejado
2. Leia a descrição, requisitos e conteúdo
3. Clique em **"Iniciar Curso"**
4. Confirme sua matrícula

**💡 Dica:** Cursos são gratuitos e sem limite de matrículas!

### 3. Assistindo Aulas

#### Vídeo-aulas

```
┌─────────────────────────────────────────────┐
│  🎥 VIDEO PLAYER                            │
│  ┌─────────────────────────────────────┐   │
│  │                                     │   │
│  │         [▶ Play]                   │   │
│  │                                     │   │
│  └─────────────────────────────────────┘   │
│  ⏮  ⏯  ⏭  🔊  ⚙️  ⛶                    │
│                                             │
│  Lição 2.1: Conceitos Básicos              │
│  ████████░░░░ 75% concluída                │
│                                             │

│  • Slides da aula.pdf                       │
│  • Exercícios.zip                           │
└─────────────────────────────────────────────┘
```

**Controles do player:**
- ⏯ **Play/Pause** - Iniciar ou pausar
- ⏮ ⏭ **Pular** - Voltar/avançar 10 segundos
- 🔊 **Volume** - Ajustar som
- ⚙️ **Configurações** - Velocidade (0.5x a 2x), qualidade
- ⛶ **Tela cheia** - Modo imersivo

**💡 Dicas:**
- Seu progresso é salvo automaticamente a cada 10 segundos
- Você pode retomar de onde parou
- Aulas são marcadas como concluídas ao assistir 90%

#### Aulas em Texto

1. Leia o conteúdo com calma
2. Use os recursos adicionais (links, PDFs)
3. Clique em **"Marcar como Concluída"** ao terminar

**💡 Dica:** Textos mostram tempo estimado de leitura!

## 🏆 Gamificação

### Sistema de XP (Pontos de Experiência)

**Como ganhar XP:**

| Ação | XP Ganho |
|------|----------|
| Lição completa | 50 XP |
| Quiz aprovado | 100 XP |
| Quiz com nota perfeita | 200 XP |
| Curso completo | 500 XP |
| Primeiro curso | 1.000 XP (bônus) |
| Sequência de 7 dias | 300 XP |

**Níveis:**

```
Nível 1:  0 XP       → Iniciante
Nível 2:  1.000 XP   → Aprendiz
Nível 3:  2.500 XP   → Praticante
Nível 4:  5.000 XP   → Experiente
Nível 5:  10.000 XP  → Expert
Nível 10: 100.000 XP → Mestre
```

**💡 Dica:** Cada level up desbloqueia um badge especial!

### Badges e Conquistas

**Tipos de badges:**

🎯 **Milestones**
- 🎓 Primeira Conclusão - Complete seu primeiro curso
- 🔟 Dez Cursos - Complete 10 cursos
- 💯 Perfeição - Obtenha 100% em 5 quizzes

⚡ **Velocidade**
- 🚀 Veloz - Complete curso em menos de 24h
- ⏰ Madrugador - Estude antes das 7h da manhã
- 🌙 Coruja - Estude depois das 23h

🏅 **Especialização**
- 🤖 Mestre da IA - Complete todos os cursos de IA
- 📋 Expert em Propostas - Complete trilha de propostas
- 📊 Analista Pro - Complete cursos de analytics

🏆 **Ranking**
- 🥇 Top 10 - Entre no top 10 do leaderboard
- 👑 Número 1 - Fique em primeiro lugar
- 📈 Em Alta - Maior ganho de XP na semana

**Visualizar badges:**
1. Clique em **"Conquistas"** no menu
2. Veja seus badges conquistados
3. Veja progresso para próximos badges

## 📜 Certificados

### Obtendo Certificados

**Requisitos:**
- ✅ Completar 100% do curso
- ✅ Passar em todos os quizzes (quando aplicável)
- ✅ CPF cadastrado no perfil

**Geração:**
- Certificados são gerados **automaticamente**
- Você recebe email de notificação
- Disponível para download imediatamente

### Visualizando Certificados

1. Clique em **"Conquistas"** no menu
2. Selecione aba **"Certificados"**
3. Veja todos os seus certificados

```
┌─────────────────────────────────────────────┐
│  📜 MEUS CERTIFICADOS                       │
├─────────────────────────────────────────────┤
│  [Thumbnail]                                │
│  Introdução ao Extrata                      │
│  Concluído em: 15/01/2025                   │
│  Carga horária: 8h                          │
│  🔗 Validar | 📥 Baixar | 📤 Compartilhar  │
└─────────────────────────────────────────────┘
```

### Compartilhando Certificados

**LinkedIn:**
1. Clique em **"Compartilhar"** no certificado
2. Selecione **"LinkedIn"**
3. Autorize compartilhamento
4. Certificado aparece no seu perfil

**Download:**
- Formato: PDF
- Inclui: Nome, CPF, curso, data, QR Code
- QR Code permite validação online

### Validando Certificados

**Validar certificado de terceiros:**
1. Acesse: https://academy.extrata.gov.br/validar
2. Digite o **código do certificado** (no rodapé do PDF)
3. Ou escaneie o **QR Code**
4. Sistema mostra informações do certificado

## 📝 Criando um Curso

### 1. Acessar o Editor

1. Clique em **"Cursos"** no menu
2. Clique em **"Criar Novo Curso"**
3. Você verá o **Editor de Cursos**

### 2. Informações Básicas

**Preencha:**

```
Título: _______________________________
(Ex: "Introdução ao Módulo de Propostas")

Descrição: ____________________________
(Breve resumo do que o curso ensina)

Categoria: [ Dropdown ]
- Fundamentos
- Propostas
- Analytics
- IA e Automação
- Avançado

Nível: [ Dropdown ]
- Iniciante
- Intermediário
- Avançado

Duração estimada: _____ horas

Thumbnail: [Upload de imagem]
(Recomendado: 800x600px, formato JPG/PNG)
```

**💡 Dicas:**
- Título claro e direto
- Descrição com 2-3 frases
- Thumbnail atrativo e profissional

### 3. Estruturando o Curso

#### Criar Módulos

```
Curso: Introdução ao Extrata
│
├── Módulo 1: Fundamentos
│   ├── Lição 1.1: O que é o Extrata?
│   ├── Lição 1.2: Como funciona?
│   └── Quiz 1
│
├── Módulo 2: Cadastro de Propostas
│   ├── Lição 2.1: Tipos de proposta
│   ├── Lição 2.2: Preencher dados
│   └── Quiz 2
│
└── Módulo 3: Monitoramento
    └── ...
```

**Criar módulo:**
1. Clique em **"+ Adicionar Módulo"**
2. Digite o **nome do módulo**
3. Clique em **"Salvar"**

**Reordenar:**
- Arraste e solte módulos para reordenar
- Mesma coisa para lições dentro de módulos

#### Criar Lições

**Tipos de lição:**
1. 🎥 **Vídeo** - Vídeo-aula
2. 📝 **Texto** - Conteúdo escrito
3. ❓ **Quiz** - Avaliação

### 4. Criando Lição de Vídeo

```
┌─────────────────────────────────────────────┐
│  Nova Lição de Vídeo                        │
├─────────────────────────────────────────────┤
│  Título: ______________________________     │
│                                             │
│  Descrição: ___________________________     │
│  _________________________________________  │
│                                             │
│  Upload de Vídeo:                           │
│  [Clique ou arraste arquivo]                │
│  Formatos: MP4, MOV, AVI (max 500MB)       │
│                                             │
│  OU insira URL do YouTube:                  │
│  https://youtube.com/watch?v=___________    │
│                                             │
│  Duração: ___ min  (preenchido auto)        │
│                                             │
│  Recursos adicionais:                       │
│  [+ Adicionar PDF, Slides, Links]           │
│                                             │
│  [Cancelar]  [Salvar Rascunho]  [Publicar] │
└─────────────────────────────────────────────┘
```

**💡 Dicas de vídeo:**
- Qualidade mínima: 720p (HD)
- Duração ideal: 5-15 minutos
- Use legendas (acessibilidade)
- Organize em capítulos (se longo)

### 5. Criando Lição de Texto

**Editor rich text:**
- Formatação: **negrito**, *itálico*, ~~tachado~~
- Headings: # H1, ## H2, ### H3
- Listas: numeradas ou bullet points
- Links: [texto](url)
- Imagens: Upload inline
- Code blocks: ```código```
- Vídeos embedded: YouTube, Vimeo

**Estrutura recomendada:**

```markdown
# Título da Lição

## Introdução
Breve contexto...

## Conteúdo Principal
### Tópico 1
Explicação...

### Tópico 2
Explicação...

## Exemplos Práticos
- Exemplo 1
- Exemplo 2

## Resumo
Recapitulação dos pontos principais...

## Próximos Passos
O que fazer após esta lição...
```

### 6. Criando Quiz

#### Configurações do Quiz

```
Nome do Quiz: _________________________

Nota mínima: ___% (padrão: 70%)

Tentativas máximas: ___ (padrão: 3)

Tempo limite: ___ minutos (opcional)

[ ] Embaralhar questões
[ ] Embaralhar respostas
[ ] Mostrar resposta correta após submissão
```

#### Adicionar Questões

**Questão de Múltipla Escolha:**

```
Pergunta: _____________________________
______________________________________

Tipo: ○ Única resposta  ○ Múltiplas respostas

Opções:
[ ] A) _______________________________
[✓] B) _______________________________ (correta)
[ ] C) _______________________________
[ ] D) _______________________________

[+ Adicionar opção]

Explicação (opcional): _________________
(Mostrada após resposta)

Pontos: ___ (padrão: 1)
```

**Questão Verdadeiro/Falso:**

```
Afirmação: ____________________________
______________________________________

Resposta correta: ○ Verdadeiro  ● Falso

Explicação: ___________________________
```

**💡 Dicas de quiz:**
- 5-10 questões por quiz
- Misture dificuldades
- Adicione explicações às respostas
- Teste o quiz antes de publicar

## 📚 Gestão de Cursos

### Aprovar Cursos

**Fluxo de aprovação:**
1. Instrutor cria curso (status: DRAFT)
2. Instrutor solicita revisão
3. Admin revisa e aprova/rejeita
4. Se aprovado → status: PUBLISHED

**Revisar curso pendente:**
1. **"Admin"** → **"Cursos Pendentes"**
2. Clique no curso
3. Revise:
   - Conteúdo completo?
   - Qualidade adequada?
   - Informações corretas?
4. Ação:
   - ✅ **Aprovar** → Publica imediatamente
   - ❌ **Rejeitar** → Volta para instrutor com feedback

### Gerenciar Todos os Cursos

**Ações de admin:**
- 👁️ Visualizar qualquer curso
- ✏️ Editar qualquer curso
- 🗑️ Arquivar curso
- 📊 Ver analytics
- 🚀 Destacar curso (featured)

3. Email está verificado?

1. Usuário completou 100%?

```bash
Admin → Certificados → Gerar Manualmente

Admin → Cursos → [Buscar curso]
→ Verificar status → Publicar
→ Admin → Manutenção → Limpar cache
```

# 🔧 GUIA DE TROUBLESHOOTING

## Problemas Comuns e Soluções

### 🔐 Login e Autenticação

**Problema: Não consigo fazer login**

**Soluções:**
1. Verifique suas credenciais do Extrata
2. Tente fazer logout e login novamente no Extrata
3. Limpe cache e cookies do navegador
4. Tente em navegação anônima
5. Entre em contato: suporte@extrata.gov.br

**Problema: Sessão expira rapidamente**

**Solução:**
- Isso é normal após 15 minutos de inatividade
- Suas atividades são salvas automaticamente
- Faça login novamente para continuar

---

### 🎥 Vídeos

**Problema: Vídeo não carrega**

**Soluções:**
1. Verifique sua conexão de internet
2. Tente diminuir a qualidade (⚙️ → Qualidade → 480p)
3. Recarregue a página (F5)
4. Tente outro navegador
5. Desative extensões (AdBlock, etc.)

**Problema: Vídeo trava/buffers muito**

**Soluções:**
1. Pause o vídeo por 10 segundos
2. Reduza a qualidade para 360p ou 480p
3. Verifique velocidade da internet (min: 2 Mbps)
4. Feche outras abas/apps consumindo internet

**Problema: Progresso do vídeo não salva**

**Solução:**
- Progresso salva a cada 10 segundos automaticamente
- Certifique-se de estar logado
- Não feche o navegador imediatamente após terminar

---

### ❓ Quizzes

**Problema: Quiz não submete**

**Soluções:**
1. Verifique se respondeu todas as questões
2. Aguarde 2-3 segundos após clicar em "Submeter"
3. Se persistir, recarregue e tente novamente
4. Entre em contato se problema continuar

**Problema: Usei todas as tentativas**

**Solução:**
- Cada quiz permite 3 tentativas (padrão)
- Revise o conteúdo do módulo
- Solicite reset ao instrutor (Admin → Suporte)

---

### 📜 Certificados

**Problema: Certificado não foi gerado**

**Verificar:**
- [ ] Completou 100% do curso?
- [ ] Passou em todos os quizzes?
- [ ] CPF está cadastrado no perfil?

**Solução:**
1. Complete todos os requisitos
2. Aguarde até 24h
3. Se não gerar, contate: suporte@extrata.gov.br

**Problema: Erro ao baixar certificado**

**Soluções:**
1. Tente novamente após 1 minuto
2. Tente outro navegador
3. Clique com botão direito → "Salvar link como"

# 📝 APÊNDICES

## A. Glossário

- **LMS** - Learning Management System (Sistema de Gestão de Aprendizagem)
- **XP** - Experience Points (Pontos de Experiência)
- **Badge** - Emblema ou conquista digital
- **Leaderboard** - Ranking ou tabela de classificação
- **Quiz** - Avaliação ou teste de conhecimento
- **Módulo** - Conjunto de lições sobre um tema
- **Lição** - Unidade de aprendizado (vídeo, texto ou quiz)
- **Draft** - Rascunho (não publicado)
- **Published** - Publicado (visível para todos)

## B. Atalhos de Teclado

**Player de vídeo:**
- `Space` - Play/Pause
- `←` - Voltar 10 segundos
- `→` - Avançar 10 segundos
- `↑` - Aumentar volume
- `↓` - Diminuir volume
- `F` - Tela cheia
- `M` - Mudo
- `1-9` - Pular para % do vídeo

**Navegação:**
- `Ctrl + K` - Buscar cursos
- `G então H` - Ir para Home
- `G então C` - Ir para Cursos
- `G então P` - Ir para Perfil
