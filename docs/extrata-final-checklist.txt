### Dia 4: Backend Setup

- [ ] **Inicializar NestJS**
  ```bash
  cd backend
  npx @nestjs/cli new . --strict --package-manager npm
  ```

- [ ] **Instalar dependências principais**
  ```bash
  npm install --save @nestjs/config @nestjs/typeorm typeorm pg \
    @nestjs/passport passport passport-jwt @nestjs/jwt \
    @nestjs/swagger class-validator class-transformer bcrypt \
    redis ioredis @nestjs/cache-manager
  
  npm install --save-dev @types/passport-jwt @types/bcrypt
  ```

- [ ] **Configurar arquivos base**
  - [ ] .env (copiar de .env.example)
  - [ ] database.config.ts
  - [ ] app.module.ts (imports base)

- [ ] **Criar estrutura de módulos**
  ```bash
  nest g module database
  nest g module config
  nest g module auth
  nest g module users
  nest g module courses
  ```

- [ ] **Configurar TypeORM**
  - [ ] Database config
  - [ ] Entities folder
  - [ ] Migrations folder

- [ ] **Testar backend**
  ```bash
  npm run start:dev
  # Acessar http://localhost:4000
  ```

### Dia 5: Frontend Setup

- [ ] **Inicializar Next.js**
  ```bash
  cd frontend
  npx create-next-app@latest . --typescript --tailwind --app --src-dir
  ```

- [ ] **Instalar dependências**
  ```bash
  npm install @tanstack/react-query zustand axios \
    zod react-hook-form @hookform/resolvers lucide-react \
    clsx tailwind-merge next-themes
  ```

- [ ] **Setup shadcn/ui**
  ```bash
  npx shadcn-ui@latest init
  npx shadcn-ui@latest add button card input label select badge avatar skeleton
  ```

- [ ] **Criar estrutura base**
  - [ ] app/(auth)/login/page.tsx

  - [ ] components/ui/ (shadcn)
  - [ ] lib/api/client.ts

- [ ] **Copiar componente exemplo**
  - [ ] CourseCard.tsx para components/academy/

- [ ] **Testar frontend**
  ```bash

  # Acessar http://localhost:3000
  ```
