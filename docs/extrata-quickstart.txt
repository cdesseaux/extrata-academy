## ⚡ Setup Rápido (5 minutos)

### Pré-requisitos
```bash
# Verifique se tem instalado:
node --version  # v20+
npm --version   # v10+
docker --version
docker-compose --version
git --version
```

### Instalação Automatizada

```bash
# 1. Criar pasta do projeto
mkdir extrata-academy
cd extrata-academy

# 2. Criar estrutura de pastas
mkdir -p docs backend frontend shared infrastructure scripts

# 3. Copiar todos os arquivos .md para docs/

# 4. Copiar arquivos de configuração para raiz:
#    - docker-compose.yml
#    - .env.example
#    - README.md

# 5. Copiar setup-dev.sh para scripts/
mkdir -p scripts
# (cole o conteúdo de setup-dev.sh em scripts/setup-dev.sh)

# 6. Executar setup
chmod +x scripts/setup-dev.sh
./scripts/setup-dev.sh
```

O script vai:
- ✅ Verificar pré-requisitos
- ✅ Criar estrutura de pastas
- ✅ Gerar .env com secrets aleatórios
- ✅ Inicializar backend NestJS
- ✅ Inicializar frontend Next.js
- ✅ Instalar todas as dependências
- ✅ Subir Docker (PostgreSQL, Redis, Keycloak)
- ✅ Inicializar Git

## 🎯 Setup Manual (se preferir controle total)

### 1. Estrutura de Pastas

```bash
mkdir -p extrata-academy/{backend,frontend,shared,docs,infrastructure,scripts}
cd extrata-academy
```

### 2. Documentação

```bash
# Criar pasta docs
mkdir -p docs/assets/{diagrams,wireframes,screenshots}

# Copiar todos os arquivos .md para docs/
# Copiar README.md para raiz
```

### 3. Configuração

```bash
# Copiar arquivos de configuração
cp docker-compose.yml .
cp .env.example .env

# Editar .env com suas credenciais
nano .env
```

### 4. Docker Infrastructure

```bash
# Subir PostgreSQL, Redis, Keycloak
docker-compose up -d postgres redis keycloak

# Verificar status
docker-compose ps

# Ver logs
docker-compose logs -f
```

### 5. Backend (NestJS)

```bash
cd backend

# Criar projeto NestJS
npx @nestjs/cli new . --strict --package-manager npm

# Instalar dependências
npm install --save \
  @nestjs/config \
  @nestjs/typeorm typeorm pg \
  @nestjs/passport passport passport-jwt @nestjs/jwt \
  @nestjs/swagger \
  class-validator class-transformer \
  bcrypt redis ioredis

npm install --save-dev \
  @types/passport-jwt \
  @types/bcrypt

# Iniciar dev server
npm run start:dev
```

### 6. Frontend (Next.js)

```bash
cd frontend

# Criar projeto Next.js
npx create-next-app@latest . \
  --typescript \
  --tailwind \
  --app \
  --src-dir

# Instalar dependências
npm install \
  @tanstack/react-query \
  zustand \
  axios \
  zod react-hook-form \
  lucide-react

# Setup shadcn/ui
npx shadcn-ui@latest init
npx shadcn-ui@latest add button card input

# Iniciar dev server
npm run dev
```

## 🐛 Troubleshooting

### Porta já em uso

```bash
# Encontrar processo
lsof -i :4000
lsof -i :3000

# Matar processo
kill -9 <PID>
```

### Docker não conecta

```bash
# Restart containers
docker-compose restart

# Ver logs
docker-compose logs -f postgres
docker-compose logs -f redis
docker-compose logs -f keycloak

# Recrear containers
docker-compose down -v
docker-compose up -d
```

### Banco de dados não conecta

```bash
# Verificar se está rodando
docker ps | grep postgres

# Acessar diretamente
docker exec -it extrata-academy-postgres psql -U academy -d academy

# Verificar credenciais no .env
cat .env | grep DB_
```

### Node modules corrompidos

```bash
# Limpar e reinstalar
cd backend
rm -rf node_modules package-lock.json
npm install

cd ../frontend
rm -rf node_modules package-lock.json .next
npm install
```
