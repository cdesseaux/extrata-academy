# 📋 EXTRATA ACADEMY - Requisitos Funcionais e Não-Funcionais

> **Versão**: 2.0 (Atualizado em 06/10/2025)  
> **Changelog**: Adicionados RF-007 (Integração Extrata), RNF-008 (Compliance), RNF-009 (Observabilidade)

## 🎯 Requisitos Funcionais

### RF-001: Autenticação e Autorização

#### RF-001.1: Login via SSO (Keycloak)
**Prioridade**: 🔴 Crítica  
**Descrição**: Usuário deve fazer login usando credenciais do Extrata via Keycloak  
**Critérios de Aceitação**:
- [ ] Usuário clica em "Entrar" e é redirecionado para Keycloak
- [ ] Após autenticação, retorna para Academy com sessão ativa
- [ ] Token JWT é armazenado e usado em todas as requisições
- [ ] Logout invalida token e limpa sessão
- [ ] Session sharing com Extrata Main funciona

#### RF-001.2: Controle de Acesso Baseado em Roles
**Prioridade**: 🔴 Crítica  
**Roles**:
- `ADMIN`: Acesso total, gerencia cursos e usuários
- `INSTRUCTOR`: Cria e edita cursos
- `STUDENT`: Acessa e completa cursos
- `AUDITOR`: Visualiza relatórios e analytics

**Critérios de Aceitação**:
- [ ] Roles são sincronizadas do Keycloak
- [ ] Permissões são verificadas no backend
- [ ] UI mostra/esconde features baseado em role

---

### RF-002: Gestão de Cursos

#### RF-002.1: Criar Curso
**Prioridade**: 🔴 Crítica  
**Ator**: ADMIN, INSTRUCTOR  
**Descrição**: Criar novo curso com metadados básicos

**Campos**:
- Título (obrigatório, max 255 chars)
- Descrição (obrigatório, rich text)
- Categoria (select: Iniciante/Intermediário/Avançado)
- Duração estimada (horas)
- Thumbnail (upload de imagem)
- Status (draft/published/archived)

**Critérios de Aceitação**:
- [ ] Form de criação com validação
- [ ] Curso criado como draft por padrão
- [ ] Slug gerado automaticamente a partir do título
- [ ] Thumbnail é redimensionado e armazenado

#### RF-002.2: Estruturar Curso (Módulos e Lições)
**Prioridade**: 🔴 Crítica  
**Descrição**: Organizar curso em módulos e lições

**Estrutura**:
```
Curso
├── Módulo 1
│   ├── Lição 1.1 (vídeo)
│   ├── Lição 1.2 (texto)
│   └── Lição 1.3 (quiz)
└── Módulo 2
    ├── Lição 2.1
    └── Lição 2.2
```

**Critérios de Aceitação**:
- [ ] Criar/editar/deletar módulos
- [ ] Criar/editar/deletar lições
- [ ] Reordenar módulos e lições (drag & drop)
- [ ] Marcar lições como obrigatórias
- [ ] Preview antes de publicar

#### RF-002.3: Publicar Curso
**Prioridade**: 🟡 Alta  
**Descrição**: Tornar curso disponível para alunos

**Validações**:
- Curso deve ter pelo menos 1 módulo
- Módulo deve ter pelo menos 1 lição
- Todas as lições devem ter conteúdo

**Critérios de Aceitação**:
- [ ] Validações impedem publicação incompleta
- [ ] Notificação para alunos inscritos
- [ ] Aparece na lista de cursos disponíveis

#### RF-002.4: Versionamento de Curso
**Prioridade**: 🟢 Média  
**Descrição**: Manter histórico de versões do curso

**Critérios de Aceitação**:
- [ ] Cada mudança cria nova versão
- [ ] Alunos continuam na versão matriculada
- [ ] Admin pode ver histórico de versões
- [ ] Pode reverter para versão anterior

### RF-003: Tipos de Conteúdo

#### RF-003.1: Lição de Vídeo
**Prioridade**: 🔴 Crítica  
**Descrição**: Reproduzir vídeo com tracking de progresso

**Features**:
- Player HTML5 com controles
- Adaptive streaming (múltiplas qualidades)
- Legendas/transcrições
- Speed control (0.5x - 2x)
- Fullscreen
- Picture-in-picture

**Tracking**:
- Tempo assistido
- % de conclusão (considera 90% como completo)
- Tentativas de pular (prevenção opcional)

**Critérios de Aceitação**:
- [ ] Vídeo é reproduzido sem buffering excessivo
- [ ] Progress é salvo a cada 10 segundos
- [ ] Usuário pode retomar de onde parou
- [ ] Marca como completa após 90% assistido

#### RF-003.2: Lição de Texto
**Prioridade**: 🔴 Crítica  
**Descrição**: Exibir conteúdo textual formatado

**Editor**: Rich text (Markdown ou WYSIWYG)  
**Suporte**:
- Headings, bold, italic, lists
- Links, imagens
- Code blocks
- Embeds (YouTube, etc)

**Critérios de Aceitação**:
- [ ] Conteúdo é renderizado corretamente
- [ ] Responsivo (mobile-friendly)
- [ ] Botão "Marcar como concluída"
- [ ] Tempo de leitura estimado

#### RF-003.3: Lição de Quiz
**Prioridade**: 🔴 Crítica  
**Descrição**: Avaliação do aprendizado

**Tipos de Questão**:
- Múltipla escolha (single/multiple answers)
- Verdadeiro/Falso
- Dissertativa (futuro)

**Configurações**:
- Nota mínima para aprovação (padrão: 70%)
- Máximo de tentativas (padrão: 3)
- Tempo limite (opcional)
- Embaralhar questões
- Mostrar resposta correta após submissão

**Critérios de Aceitação**:
- [ ] Quiz exibe questões corretamente
- [ ] Valida respostas
- [ ] Calcula nota automaticamente
- [ ] Permite retentativas (até limite)
- [ ] Grava histórico de tentativas

### RF-004: Experiência do Aluno

#### RF-004.1: Navegar Cursos
**Prioridade**: 🔴 Crítica  
**Descrição**: Descobrir e explorar cursos disponíveis

**Features**:
- Catálogo com cards de cursos
- Filtros (categoria, nível, duração)
- Busca por palavra-chave
- Ordenação (popularidade, recentes, nome)
- Preview do curso (descrição, módulos, reviews)

**Critérios de Aceitação**:
- [ ] Catálogo carrega em < 2s
- [ ] Filtros funcionam corretamente
- [ ] Busca retorna resultados relevantes
- [ ] Preview mostra informações completas

#### RF-004.2: Matricular-se em Curso
**Prioridade**: 🔴 Crítica  
**Descrição**: Aluno se inscreve em curso

**Fluxo**:
1. Clica em "Iniciar Curso"
2. Confirma matrícula
3. Redirecionado para primeira lição

**Critérios de Aceitação**:
- [ ] Matrícula criada no banco
- [ ] Aparece em "Meus Cursos"
- [ ] Email de confirmação enviado (opcional)
- [ ] Previne duplicação de matrícula

#### RF-004.3: Acompanhar Progresso
**Prioridade**: 🔴 Crítica  
**Descrição**: Ver progresso individual em cursos

**Métricas**:
- % de conclusão
- Lições completas / total
- Tempo gasto
- Última atividade
- Próxima lição

**Critérios de Aceitação**:
- [ ] Progresso atualiza em tempo real
- [ ] Barra de progresso visual
- [ ] Dashboard de "Meus Cursos" mostra status
- [ ] Notificação ao completar curso

#### RF-004.4: Obter Certificado
**Prioridade**: 🔴 Crítica  
**Descrição**: Gerar certificado ao completar curso

**Requisitos**:
- 100% do curso completo
- Nota >= mínima em todos os quizzes
- CPF cadastrado

**Certificado inclui**:
- Nome do aluno
- CPF (para validação)
- Nome do curso
- Carga horária
- Data de conclusão
- QR Code de validação

**Critérios de Aceitação**:
- [ ] Certificado gerado automaticamente
- [ ] PDF disponível para download
- [ ] QR Code permite validação online
- [ ] Email com certificado enviado

### RF-005: Gamificação

#### RF-005.1: Sistema de XP
**Prioridade**: 🟡 Alta  
**Descrição**: Ganhar pontos por atividades

**Recompensas**:
| Ação | XP |
|------|-----|
| Lição completa | 50 |
| Quiz aprovado | 100 |
| Quiz com nota perfeita | 200 |
| Curso completo | 500 |
| Primeiro curso | 1000 (bônus) |
| Streak 7 dias | 300 |

**Critérios de Aceitação**:
- [ ] XP é creditado imediatamente
- [ ] Notificação visual de ganho de XP
- [ ] Total de XP visível no perfil

#### RF-005.2: Níveis
**Prioridade**: 🟡 Alta  
**Descrição**: Progredir através de níveis

**Curva**:
- Nível 1: 0 XP
- Nível 2: 1.000 XP
- Nível 3: 2.500 XP
- Nível 4: 5.000 XP
- Nível 5: 10.000 XP
- Nível 10: 100.000 XP

**Critérios de Aceitação**:
- [ ] Level up é comemorado (animação)
- [ ] Badge de nível visível
- [ ] Progresso para próximo nível mostrado

#### RF-005.3: Badges/Conquistas
**Prioridade**: 🟢 Média  
**Descrição**: Desbloquear badges por milestones

**Exemplos**:
- 🎯 Primeira Proposta: Complete primeiro curso
- 🤖 Mestre da IA: Complete todos os cursos de IA
- ⚡ Veloz: Complete curso em <24h
- 🏆 Top 10: Fique no top 10 do leaderboard
- 🎓 Mentor: Ajude 10 colegas (community)

**Critérios de Aceitação**:
- [ ] Badges são desbloqueados automaticamente
- [ ] Notificação de novo badge
- [ ] Vitrine de badges no perfil
- [ ] Progresso para badges próximos

#### RF-005.4: Leaderboard
**Prioridade**: 🟢 Média  
**Descrição**: Ranking de usuários por XP

**Filtros**:
- Global (todos)
- Por município
- Por role

**Critérios de Aceitação**:
- [ ] Top 100 exibidos
- [ ] Posição do usuário destacada
- [ ] Atualiza em tempo real (ou cache de 5min)
- [ ] Filtros funcionam

### RF-006: Analytics e Relatórios

#### RF-006.1: Dashboard Administrativo
**Prioridade**: 🟡 Alta  
**Ator**: ADMIN, AUDITOR  
**Descrição**: Visão geral de métricas

**Métricas**:
- Total de usuários ativos
- Total de matrículas
- Taxa de conclusão média
- Cursos mais populares
- Tempo médio de conclusão
- Usuários mais engajados

**Critérios de Aceitação**:
- [ ] Gráficos interativos
- [ ] Filtros por período
- [ ] Export para CSV/PDF
- [ ] Atualiza em tempo real

#### RF-006.2: Relatório de Progresso Individual
**Prioridade**: 🟡 Alta  
**Ator**: ADMIN, GESTOR  
**Descrição**: Ver progresso detalhado de um usuário

**Informações**:
- Cursos em andamento
- Cursos concluídos
- Certificados obtidos
- XP e nível
- Tempo total gasto
- Últimas atividades

**Critérios de Aceitação**:
- [ ] Busca por nome/email
- [ ] Visualização detalhada
- [ ] Timeline de atividades
- [ ] Export de relatório

#### RF-006.3: Relatório de Curso
**Prioridade**: 🟢 Média  
**Ator**: ADMIN, INSTRUCTOR  
**Descrição**: Métricas de um curso específico

**Métricas**:
- Total de matrículas
- Taxa de conclusão
- Tempo médio de conclusão
- Lições com maior abandono
- Scores médios de quizzes
- Feedback dos alunos

**Critérios de Aceitação**:
- [ ] Gráficos por lição
- [ ] Identifica gargalos
- [ ] Sugestões de melhoria

### RF-007: Integração com Extrata Main ⭐ NOVO

#### RF-007.1: Sincronização de Usuários
**Prioridade**: 🔴 Crítica  
**Descrição**: Sincronizar dados de usuários do Extrata Main em tempo real

**Fontes de Sincronização**:
- Webhooks (tempo real)
- API polling (fallback)
- Manual (admin trigger)

**Critérios de Aceitação**:
- [ ] Webhook recebe evento de novo usuário
- [ ] Dados são sincronizados em < 1 segundo
- [ ] Fallback usa dados em cache se API falhar
- [ ] Circuit breaker protege contra falhas em cascata
- [ ] Retry automático com backoff exponencial

#### RF-007.2: Deep Links entre Sistemas
**Prioridade**: 🟡 Alta  
**Descrição**: Links diretos do Extrata → Academy e vice-versa

**Links suportados**:
- Extrata → Curso específico
- Extrata → Matrícula automática
- Academy → Perfil no Extrata
- Academy → Dashboard Extrata

**Critérios de Aceitação**:
- [ ] Link para curso específico funciona
- [ ] Context é preservado entre sistemas
- [ ] Session sharing funciona
- [ ] Tokens são válidos em ambos os sistemas

#### RF-007.3: Webhook Handler
**Prioridade**: 🔴 Crítica  
**Descrição**: Processar eventos do Extrata Main

**Eventos suportados**:
- `user.created` - Novo usuário
- `user.updated` - Dados alterados
- `user.deleted` - Usuário removido
- `municipality.created` - Novo município

**Critérios de Aceitação**:
- [ ] Assinatura HMAC validada
- [ ] Eventos processados de forma idempotente
- [ ] Retry automático em caso de falha
- [ ] Logs de auditoria completos

#### RF-007.4: API Client do Extrata
**Prioridade**: 🔴 Crítica  
**Descrição**: Cliente para consumir APIs do Extrata

**Features**:
- Service account authentication
- Token refresh automático
- Circuit breaker
- Cache de fallback
- Rate limiting

**Critérios de Aceitação**:
- [ ] Autenticação OAuth2 funciona
- [ ] Tokens são renovados automaticamente
- [ ] Circuit breaker abre após 5 falhas
- [ ] Cache é usado quando API está indisponível
- [ ] Rate limit respeitado (100 req/min)

## 🔧 Requisitos Não-Funcionais

### RNF-001: Performance
**Prioridade**: 🔴 Crítica

- **RNF-001.1**: API response time < 200ms (p95)
- **RNF-001.2**: Page load time < 2s (p95)
- **RNF-001.3**: Video start time < 3s
- **RNF-001.4**: Suportar 500 usuários simultâneos sem degradação
- **RNF-001.5**: Database queries < 50ms (p95)

### RNF-002: Disponibilidade
**Prioridade**: 🔴 Crítica

- **RNF-002.1**: Uptime >= 99.5% (máximo 3.65h downtime/mês)
- **RNF-002.2**: RPO (Recovery Point Objective) = 1h
- **RNF-002.3**: RTO (Recovery Time Objective) = 2h
- **RNF-002.4**: Backups diários automáticos
- **RNF-002.5**: Disaster recovery plan documentado
- **RNF-002.6**: Failover automático configurado ⭐ NOVO

### RNF-003: Segurança
**Prioridade**: 🔴 Crítica

- **RNF-003.1**: Autenticação via OAuth2/OpenID Connect (Keycloak)
- **RNF-003.2**: Comunicação via HTTPS (TLS 1.3)
- **RNF-003.3**: Tokens JWT com expiração (15min access, 7d refresh)
- **RNF-003.4**: Rate limiting (100 req/min por IP)
- **RNF-003.5**: SQL injection prevention (prepared statements)
- **RNF-003.6**: XSS prevention (sanitização de inputs)
- **RNF-003.7**: CSRF protection
- **RNF-003.8**: Compliance LGPD (dados de usuários)
- **RNF-003.9**: Security headers (CSP, HSTS, X-Frame-Options) ⭐ NOVO
- **RNF-003.10**: Secrets management (AWS Secrets Manager) ⭐ NOVO
- **RNF-003.11**: Penetration testing trimestral ⭐ NOVO

### RNF-004: Escalabilidade
**Prioridade**: 🟡 Alta

- **RNF-004.1**: Stateless backend (horizontal scaling)
- **RNF-004.2**: Database connection pooling
- **RNF-004.3**: Caching strategy (Redis)
- **RNF-004.4**: CDN para assets estáticos
- **RNF-004.5**: Async processing para tarefas pesadas
- **RNF-004.6**: Auto-scaling baseado em CPU/memória ⭐ NOVO

### RNF-005: Usabilidade
**Prioridade**: 🟡 Alta

- **RNF-005.1**: Responsive design (mobile, tablet, desktop)
- **RNF-005.2**: Acessibilidade WCAG 2.1 nível AA
- **RNF-005.3**: Suporte a navegadores modernos (últimas 2 versões)
- **RNF-005.4**: PWA (Progressive Web App)
- **RNF-005.5**: Offline-first para conteúdo baixado

### RNF-006: Manutenibilidade
**Prioridade**: 🟡 Alta

- **RNF-006.1**: Code coverage >= 80%
- **RNF-006.2**: Documentação técnica completa
- **RNF-006.3**: Código em TypeScript (type-safe)
- **RNF-006.4**: Linting e formatting automáticos
- **RNF-006.5**: Git workflow padronizado
- **RNF-006.6**: CI/CD pipeline automatizado

### RNF-007: Observabilidade
**Prioridade**: 🔴 Crítica

- **RNF-007.1**: Logging estruturado (Winston/Pino)
- **RNF-007.2**: Distributed tracing (Jaeger/Zipkin)
- **RNF-007.3**: Métricas (Prometheus/Grafana)
- **RNF-007.4**: Error tracking (Sentry)
- **RNF-007.5**: Alertas automáticos (PagerDuty/Opsgenie)

### RNF-008: Compliance e Auditoria ⭐ NOVO
**Prioridade**: 🔴 Crítica

- **RNF-008.1**: Logs de auditoria para todas as ações sensíveis
- **RNF-008.2**: Retenção de dados conforme LGPD
- **RNF-008.3**: Portal de privacidade funcional
- **RNF-008.4**: Consentimento explícito coletado e registrado
- **RNF-008.5**: Direito de acesso, correção e exclusão implementado
- **RNF-008.6**: DPO (Encarregado de Dados) nomeado e contactável
- **RNF-008.7**: Data breach response plan documentado e testado
- **RNF-008.8**: Políticas de privacidade e termos de uso publicados

### RNF-009: Observabilidade Avançada ⭐ NOVO
**Prioridade**: 🔴 Crítica

- **RNF-009.1**: SLOs definidos e monitorados (99.5% availability, <200ms p95 latency)
- **RNF-009.2**: Métricas de negócio exportadas (enrollments, completions, certificates)
- **RNF-009.3**: Logs estruturados enviados para Loki
- **RNF-009.4**: Distributed tracing com Jaeger (10% sampling em prod)
- **RNF-009.5**: Alertas configurados com severidade (critical, warning, info)
- **RNF-009.6**: Dashboards operacionais em Grafana (app, business, infra)
- **RNF-009.7**: Runbooks documentados para incidentes comuns
- **RNF-009.8**: On-call rotation definida com escalation policy

## 🚫 Out of Scope (Não é MVP)

- ❌ Mobile apps nativos (iOS/Android)
- ❌ Live classes / webinars
- ❌ Fórum / discussões (usar Discord)
- ❌ Peer-to-peer review
- ❌ Marketplace de cursos
- ❌ AI tutor / chatbot
- ❌ Social features (seguir usuários, etc)
- ❌ Multi-idioma (apenas PT-BR)
- ❌ White-label para outros clientes
