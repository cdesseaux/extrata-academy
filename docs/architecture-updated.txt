## 🛠️ Stack Tecnológico

### Frontend
- **Framework**: Next.js 14 (App Router, React Server Components)
- **UI**: Tailwind CSS, shadcn/ui
- **State**: Zustand, TanStack Query (React Query)
- **Forms**: React Hook Form + Zod
- **Charts**: Recharts
- **Icons**: Lucide React
- **Auth**: NextAuth.js (Keycloak provider)

### Backend
- **Framework**: NestJS 10 (TypeScript, Node.js 20)
- **API**: REST + GraphQL (Apollo)
- **ORM**: TypeORM
- **Validation**: class-validator, class-transformer
- **Auth**: Passport (JWT, OAuth2)
- **Queue**: Bull (Redis-based)
- **WebSockets**: Socket.io

### Database & Cache
- **Primary DB**: PostgreSQL 17
- **Cache**: Redis 7
- **Search**: (Future: Elasticsearch)

### Auth & Identity
- **SSO**: Keycloak 24
- **Protocol**: OAuth2 / OpenID Connect
- **Session**: Redis-backed

### Storage & CDN
- **Object Storage**: AWS S3
- **CDN**: Cloudflare
- **Video**: S3 + CloudFront (streaming)

### Observability ⭐ NOVO
- **Metrics**: Prometheus
- **Logs**: Winston → Loki
- **Traces**: OpenTelemetry → Jaeger
- **Dashboards**: Grafana
- **Alerts**: Alertmanager → Slack/PagerDuty
- **APM**: Elastic APM (opcional)

### DevOps & Infrastructure
- **Cloud**: AWS (ECS, RDS, S3, CloudWatch)
- **CI/CD**: GitHub Actions
- **Container**: Docker
- **Orchestration**: Docker Compose (dev), ECS (prod)
- **IaC**: Terraform (future)

#### 2. Webhook Handler
**Localização**: `backend/src/integration/webhook-handler.ts`

```typescript
@Controller('webhooks')
export class WebhookController {
  @Post('extrata')
  async handleExtrataWebhook(
    @Body() payload: WebhookPayload,
    @Headers('x-extrata-signature') signature: string,
  ) {
    // 1. Validar assinatura HMAC
    this.validateSignature(payload, signature);
    
    // 2. Processar evento de forma idempotente
    await this.processEvent(payload);
    
    // 3. Retry automático via SQS se falhar
  }
}
```

**Eventos suportados**:
- `user.created` → Sincronizar novo usuário
- `user.updated` → Atualizar dados do usuário
- `user.deleted` → Soft delete do usuário
- `municipality.created` → Adicionar município

#### 3. SSO Integration
**Flow OAuth2/OIDC completo**:

```
1. User → Academy Login
2. Academy → Redirect to Keycloak
3. User → Login no Keycloak (se necessário)
4. Keycloak → Callback com authorization code
5. Academy → Exchange code for tokens
6. Academy → Fetch user info from Keycloak
7. Academy → Sync additional data from Extrata API
8. Academy → Create/update local user
9. Academy → Create session → Redirect to dashboard
```

## 🔄 Data Flows

### Exemplo 1: Curso Completo (End-to-End)

```
1. User Login
   Browser → Next.js → Keycloak → Academy Backend
   ↓
2. Keycloak Callback
   Keycloak → Academy → Fetch Extrata API → Create Session
   ↓
3. Browse Courses
   Browser → Next.js → Academy API → PostgreSQL
   (Cache em Redis por 5min)
   ↓
4. Enroll
   Browser → POST /enrollments → PostgreSQL
   (Event: enrollment_created → Metrics)
   ↓
5. Watch Lesson
   Browser → GET /lessons/:id → PostgreSQL
   Video Stream ← S3/CloudFront
   (Progress saved every 10s)
   ↓
6. Complete Lesson
   Browser → PATCH /progress/:id → PostgreSQL
   (Event: lesson_completed → XP awarded)
   ↓
7. Take Quiz
   Browser → POST /quizzes/:id/attempts → PostgreSQL
   (Auto-grade → Update progress)
   ↓
8. Course Completed (100%)
   PostgreSQL Trigger → Certificate Generation
   S3 Upload → Email Notification
   ↓
9. Download Certificate
   Browser → GET /certificates/:id → S3 (signed URL)
```

### Exemplo 2: Sincronização de Usuário (Webhook) ⭐ NOVO

```
1. Extrata Main
   User updated → Trigger webhook
   ↓
2. Academy Webhook Endpoint
   POST /webhooks/extrata
   Validate HMAC signature
   ↓
3. Process Event
   Extract user_id from payload
   ↓
4. Fetch Full Data
   GET Extrata API /users/{user_id}
   (With circuit breaker)
   ↓
5. Update Local DB
   UPSERT users table
   Update sync_status
   ↓
6. Audit Log
   INSERT audit_logs
   (event: user_synced)
   ↓
7. Notify if Needed
   Email/Push notification (opcional)
```

### Exemplo de Implementação

**Controller**:
```typescript
@Controller('courses')
@UseGuards(JwtAuthGuard, RolesGuard)
@UseInterceptors(MetricsInterceptor, TracingInterceptor) ⭐ NOVO
export class CoursesController {
  constructor(
    private readonly coursesService: CoursesService,
    private readonly auditLogger: AuditLogger, ⭐ NOVO
  ) {}

  @Get()
  @Roles('STUDENT', 'INSTRUCTOR', 'ADMIN')
  async findAll(@Query() filters: CourseFilterDto) {
    return this.coursesService.findAll(filters);
  }

  @Post()
  @Roles('INSTRUCTOR', 'ADMIN')
  async create(
    @Body() dto: CreateCourseDto,
    @CurrentUser() user: User,
  ) {
    const course = await this.coursesService.create(dto, user.id);
    
    // Audit log ⭐ NOVO
    await this.auditLogger.log({
      event_type: 'course_created',
      user_id: user.id,
      resource_type: 'course',
      resource_id: course.id,
      action: 'CREATE',
    });
    
    return course;
  }
}
```

**Service**:
```typescript
@Injectable()
export class CoursesService {
  private readonly logger = new LoggerService(CoursesService.name); ⭐ NOVO
  
  constructor(
    @InjectRepository(Course)
    private coursesRepo: Repository<Course>,
    private cacheManager: Cache,
  ) {}

  async findAll(filters: CourseFilterDto) {
    const cacheKey = `courses:${JSON.stringify(filters)}`;
    
    // Try cache first
    const cached = await this.cacheManager.get(cacheKey);
    if (cached) {
      this.logger.log('Cache hit', { cacheKey }); ⭐ NOVO
      return cached;
    }
    
    // Query database
    const courses = await this.coursesRepo.find({ where: filters });
    
    // Cache for 5min
    await this.cacheManager.set(cacheKey, courses, 300);
    
    this.logger.log('Courses fetched', { count: courses.length }); ⭐ NOVO
    
    return courses;
  }
}
```

## 🎥 Video Streaming

### Pipeline de Processamento

```
1. Upload
   Instructor → S3 (multipart upload)
   ↓
2. Transcode (Lambda/MediaConvert)
   Original → [1080p, 720p, 480p, 360p]
   ↓
3. Store
   S3 bucket (transcoded/)
   ↓
4. Deliver
   CloudFront (CDN) → HLS/DASH
   ↓
5. Play
   Video.js player → Adaptive bitrate
```

### Player Features
- Adaptive bitrate streaming (HLS)
- Resume from last position
- Speed control (0.5x - 2x)
- Quality selector
- Fullscreen
- Picture-in-picture
- Keyboard shortcuts

### Escalabilidade

**Horizontal Scaling**:
- Frontend: Auto-scaling 2-10 tasks (CPU >70%)

- Database: t3.medium → t3.large (se necessário)

## ✅ Architecture Decision Records (ADRs)

### ADR-001: Por que NestJS?
- ✅ TypeScript nativo
- ✅ Arquitetura modular
- ✅ DI container
- ✅ Decorators para metadata
- ✅ Ecosystem maduro

### ADR-002: Por que Next.js App Router?
- ✅ Server Components (performance)
- ✅ Streaming SSR
- ✅ Built-in optimizations
- ✅ File-based routing
- ✅ API routes integradas

### ADR-003: Por que TypeORM? ⭐ ATUALIZADO
- ✅ TypeScript-first
- ✅ Migrations robustas
- ✅ Active Record + Data Mapper
- ✅ Suporte a triggers/functions
- ⚠️ **Alternativa considerada**: Prisma (melhor DX, mas menos controle sobre SQL)

### ADR-004: Por que Prometheus + Grafana? ⭐ NOVO
- ✅ Industry standard para observability
- ✅ Pull-based metrics (mais resiliente)
- ✅ Powerful query language (PromQL)
- ✅ Rich ecosystem (exporters, alerting)
- ✅ Grafana dashboards visuais e compartilháveis
