# 🎨 EXTRATA ACADEMY - Frontend Design & UX

## 🎯 Design Philosophy

**"Simples, Eficiente e Governamental"**

### Princípios de Design
1. **Clareza sobre Estilo** - Funcionalidade primeiro
2. **Acessibilidade WCAG 2.1 AA** - Todos podem usar
3. **Mobile-first** - Responsivo em todos os dispositivos
4. **Performance** - <2s page load
5. **Consistência** - Design system unificado

## ♿ Accessibility Guidelines

### WCAG 2.1 AA Compliance

**Color Contrast:**
- Text: Minimum 4.5:1 ratio
- Large text (18pt+): Minimum 3:1 ratio
- Interactive elements: Minimum 3:1 ratio

**Keyboard Navigation:**
```tsx
// All interactive elements must be keyboard accessible
<button
  onClick={handleClick}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      handleClick();
    }
  }}
  tabIndex={0}
  aria-label="Start course"
>
  Iniciar Curso
</button>
```

**ARIA Labels:**
```tsx
// Proper semantic HTML + ARIA
<nav aria-label="Main navigation">
  <ul>
    <li><a href="/dashboard">Dashboard</a></li>
  </ul>
</nav>

<button aria-label="Close modal" onClick={onClose}>
  <X />
</button>

<div role="progressbar" aria-valuenow={75} aria-valuemin={0} aria-valuemax={100}>
  75% complete
</div>
```

**Screen Reader Support:**
- Use semantic HTML (header, nav, main, aside, footer)
- Add alt text to all images
- Use aria-live for dynamic content
- Provide skip links

## 🎨 Dark Mode Support

```css
/* CSS Variables for theming */
:root {
  --bg-primary: #ffffff;
  --bg-secondary: #f9fafb;
  --text-primary: #111827;
  --text-secondary: #6b7280;
}

[data-theme="dark"] {
  --bg-primary: #111827;
  --bg-secondary: #1f2937;
  --text-primary: #f9fafb;
  --text-secondary: #9ca3af;
}
```

```tsx
// Theme Toggle
import { useTheme } from 'next-themes';

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();
  
  return (
    <button onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}>
      {theme === 'dark' ? <Sun /> : <Moon />}
    </button>
  );
}
```
