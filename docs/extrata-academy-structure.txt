## 📝 Convenções

### Arquivos
- Documentação: `NN-TOPIC-NAME.md`
- Componentes: `PascalCase.tsx`
- Utilitários: `camelCase.ts`
- Testes: `*.spec.ts`

### Código
- Variáveis: `camelCase`
- Classes: `PascalCase`
- Constantes: `UPPER_SNAKE_CASE`
- Database: `snake_case`

### Git
- Branches: `feature/nome`, `bugfix/nome`
- Commits: Conventional Commits
